CouchCHD — Linux portable distributions

Verify the downloaded artifacts against SHA256SUMS before executing them:
  sha256sum --ignore-missing -c SHA256SUMS
Compare the release tag/commit and GitHub build provenance for that exact file.

x86_64 Linux: chmod +x CouchCHD-x86_64.AppImage, then launch it from your file
manager or add the AppImage to Steam as a Non-Steam Game. If FUSE mounting is
unavailable, use ./CouchCHD-x86_64.AppImage --appimage-extract and run
squashfs-root/AppRun. Use the Gamepad with Joystick Trackpad Steam Input layout,
not a desktop/mouse layout. All CouchCHD CLI arguments pass through AppRun.

aarch64 Linux / Recalbox: use a 64-bit *userspace* (a 64-bit kernel alone is
not enough), glibc 2.36+ and an executable, writable data mount. Extract the
archive under /recalbox/share/system (it has a couchchd/ top-level directory).
Run /recalbox/share/system/couchchd/launch-recalbox.sh. The launcher does not
edit EmulationStation, remount /, or install system packages. Stop the frontend
cleanly before writing gamelist.xml or trying to acquire the KMS display. Set
QT_QPA_PLATFORM to select Wayland/XCB; without a display server the launcher
selects EGLFS, requiring a working board EGL/KMS driver and access to /dev/dri
and /dev/input. For SSH use launch-recalbox.sh --headless --help. Do not try
to install Desktop Linux glibc or GPU libraries on an incompatible Recalbox.
Keep the executable directory, ROM library and backup ledger when upgrading;
never recursively delete /recalbox/share/system/couchchd to update the app.

Both packages include Python, the Qt/QML runtime, SDL controller support and
one architecture-matched static chdman. rclone and a configured remote are
optional only for cloud pulls. Host kernel, glibc, device access, fonts and
working graphics/input drivers remain platform requirements. A native Linux CI
build and Xvfb window test do not certify a particular Recalbox or gamescope
release. Verify on copied, disposable media before using your ROM library.
