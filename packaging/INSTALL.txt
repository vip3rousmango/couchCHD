x86_64 Linux / Steam Deck: run the installer from Desktop Mode with Steam
fully exited. Setup registers the persistent run-couchchd launcher in your
native Steam library. In Gaming Mode, open Library > Non-Steam > CouchCHD.
Leave forced compatibility (Proton) off; this is a native Linux application.
Do not add a raw AppImage or an extracted AppRun as the installed shortcut.
Use the Gamepad with Joystick Trackpad Steam Input layout.

Recalbox (64-bit userspace, glibc 2.36+, writable executable SHARE):
Use scripts/install-device.sh for a persistent EmulationStation entry. When
ready, press START > QUIT > RESTART RECALBOX. Open Ports > CouchCHD. If Ports
is hidden, enable START > SYSTEM-LISTS & GAMELISTS SETTINGS > SHOW PORTS SYSTEM.
Choose Exit CouchCHD in the app to return. Setup does not restart the console.

On the Recalbox 10.1.2 Pi 4 layout, Ports aggregates registered port systems;
dropping a .sh file in roms/ports is not sufficient. The installed bundle
registers one custom port in
/recalbox/share/system/.emulationstation/systemlist.xml. Its .game extension
is registered explicitly. roms/ports/couchchd/CouchCHD.game is only a list
entry; its contents are not executed. The port's command starts the installed
/recalbox/share/system/couchchd/run-couchchd, not an emulator. Reinstalling
preserves other systems and existing gamelist metadata. No remount is needed.

ES releases its window for the launch but remains running. Do not edit game
metadata from this menu session: ES can overwrite gamelist.xml from cache.
For gamelist writes, stop ES cleanly first and run the stable launcher
separately. For a scan over SSH, use run-couchchd --headless --root
/recalbox/share/roms (all on one line). For a manual install without a menu
entry, extract the ARM archive under /recalbox/share/system and run
/recalbox/share/system/couchchd/launch-recalbox.sh with ES stopped.

Without a display server the ARM launcher selects EGLFS; it needs working
EGL/KMS drivers and /dev/dri and /dev/input access. Set QT_QPA_PLATFORM to
select Wayland/XCB instead. The menu integration is for regular HDMI output,
not CRT-adapter mode. Do not replace the OS glibc or GPU drivers, or delete
the CouchCHD data/backup ledger when upgrading. Real Pi 4 display, controller
input and return to ES have not been verified on hardware.

Both packages include Python, the Qt/QML runtime, SDL controller support and
one architecture-matched static chdman. rclone and a configured remote are
optional only for cloud pulls. Host kernel, glibc, device access, fonts and
working graphics/input drivers remain platform requirements. A native Linux CI
build and Xvfb window test do not certify a particular Recalbox or gamescope
release. Verify on copied, disposable media before using your ROM library.
